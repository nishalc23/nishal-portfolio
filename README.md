# Nishal Chintalapati — Portfolio

A scrollable portfolio with an interactive abstract particle constellation behind the entire page, work experience, projects and an about section. Uses native Canvas 2D and plain HTML/CSS/JavaScript. No build step or runtime dependencies. Drag to rotate with momentum; moving the cursor tilts the field. Reduced-motion preferences disable automatic motion.

Run `python3 -m http.server 4174` from this directory.
