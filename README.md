# Nishal Chintalapati — Portfolio

A scrollable portfolio with an interactive particle field spread across the entire viewport, work experience, projects and an about section. Uses native Canvas 2D and plain HTML/CSS/JavaScript. No build step or runtime dependencies. The constellation stays in place; particles near the cursor move away and settle back. Reduced-motion preferences disable automatic motion.

Run `python3 -m http.server 4174` from this directory.
